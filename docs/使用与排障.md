# 使用与排障

## 连接和采集

1. 给 Cyton 与 Shield 供电，确认电脑可访问 Shield IP；关闭其他 TCP/UDP 采集客户端。
2. 启动源码或打包程序，选择 WiFi UDP 并填写 Shield IP 与本地接收端口。
3. 点击连接，确认 1000 Hz、8 通道和寄存器回读状态。
4. 设置采集对象/任务及保存目录，开始采集，检查波形和包计数；结束后停止并断开。

源码默认数据目录为 `app/recordings`，打包版为 EXE 同级 `recordings`；可在界面调整。交付目录需可写。

普通采集写入 `emg_data.txt`。启用 Delsys 同步流程时，可能另有 `openbci_packets.csv`、`sync_events.jsonl`、`synchronization_report.json`；启用摄像头时另有 `camera.mp4`、`camera_frames.csv`、`camera_session.json`。具体取决于启用功能及会话是否成功完成。

## 连接失败或没有数据

- HTTP 连接失败：核对实际 IP、电脑网卡路由和 Shield 供电；UDP 仍依赖 HTTP 完成配置。
- TCP 客户端冲突：先断开其他上位机，再重试。
- HTTP 成功但无数据：核对本地 UDP 端口是否被占用，以及 Windows 防火墙是否允许对应运行程序接收 Shield 数据。
- 出现 `invalid sample value`：检查是否运行旧 EXE，或代码是否误用了 `~?`。
- 有波形后丢包/停顿：记录时间、计数、网络情况和 Shield 固件版本，按“验证与已知问题”进行长时验收。

需要防火墙规则时，在管理员 PowerShell 执行（IP 和路径换为实际值）：

```powershell
.\scripts\配置UDP防火墙.ps1 -ShieldIP 192.168.4.1 -Program '.\dist\EMG_Viewer_UDP_Sync_Camera_Impedance.exe' -Port 6677
```

源码运行时 `-Program` 应填写该环境 `python.exe` 的完整路径。脚本只允许指定 Shield IPv4、指定程序和 UDP 本地端口；会替换相同名称的既有规则。

## 摄像头和 Delsys 触发

摄像头使用 OpenCV/Windows DirectShow 的 UVC 设备。Arduino Nano 固件为 ATmega328P 16 MHz / 5 V，串口 115200，LF 或 CRLF；握手 `HELLO` 返回 `READY DELSYS_SYNC 2`。

固件使用 D2 输出约 100 ms START/STOP 共用触发脉冲，D3 保持 LOW 作为 BNC 回路返回；接线前按同事的实际 Delsys 接口要求核对。两次触发至少间隔 2 秒。命令为 `START <id>`、`STOP <id>`，响应含 id、类型、FIRED/DUP 及 MCU 微秒值；客户端不自动重试触发。

同步控制器协调前置稳定、摄像头门控、Nano 触发和边界裁剪。操作员仍需确认 Delsys 进入待触发状态及实际开始/结束结果。交付自动测试不会发送真实触发。
